# Language Guide

This guide will give a gentle introduction to the core Reform language.

If you are new to reform and just want to get started doing something
then you may want to start with the [interactive fiction
guide](../iflib/index.md) instead.

We expect most common uses of Reform to have a library that provides the
high-level syntax such as the interactive fiction one, but high level syntaxes
are probably going to be very specific to the use case.

This guide will show you how the core Reform language works so that you can
write your own syntaxes and do things that a library may not let you do out of
the box.

See the [reference](reference.md) instead for a complete description of the
Reform language on one page.
