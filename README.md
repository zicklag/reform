# Reform

Reform is a unique programming language originally designed for making
interactive fiction.

It is extremely minimal, and yet expressive, using a combination of **rules**
and **facts** for it's entire execution. It also has facilities for making
custom "plain language" parsers, within the language itself, enabling you
to create custom domain-specific languages.

The [documentation site](https://zicklag.github.io/reform/) has more information
along with a complete guide.
